# โปรแกรมการเงินโรงเรียน

โปรแกรมทะเบียนคุมเงิน / ปก / รายงานเงินคงเหลือประจำวัน ของโรงเรียนบ้านโพนเดื่อโนนสวรรค์
เปิดใช้ผ่านเว็บ (GitHub Pages) ได้ทั้งคอมพิวเตอร์ มือถือ และ iPad

- `site/index.html` ตัวโปรแกรม (ไฟล์เดียว ใช้แบบออฟไลน์ได้ด้วย)
- `src/` ซอร์สโค้ด (`node build.js` เพื่อสร้าง `out/` ใหม่ แล้วคัดลอกไปเป็น `site/index.html`)
- repo นี้มี **แค่ตัวโปรแกรม** ไม่มีข้อมูลการเงิน ข้อมูลจริงเก็บใน repo แบบ Private แยกต่างหาก

## เปิดเว็บครั้งแรก (ทำครั้งเดียว)

1. ที่ repo นี้ ไปที่ **Settings › Pages** แล้วตรง *Build and deployment › Source* เลือก **GitHub Actions**
2. ไปที่แท็บ **Actions** แล้วกด *Deploy to GitHub Pages › Run workflow* (หรือรอให้รันเองหลัง push)
3. เปิดเว็บที่ `https://<ชื่อผู้ใช้>.github.io/school-finance/`

## สร้างบัญชีครั้งแรก (ทำครั้งเดียว)

1. สร้าง repo **Private** ชื่อ `school-finance-data` (เปล่า ๆ)
2. สร้าง token ที่ https://github.com/settings/personal-access-tokens/new
   - *Repository access*: **Only select repositories** แล้วเลือก 2 repo คือ `school-finance-data` และ `school-finance`
   - *Permissions › Repositories › Contents*: **Read and write**
3. เปิดเว็บ แล้วกด **＋ สร้างบัญชีใหม่** ใส่ token แล้วตั้งชื่อผู้ใช้กับรหัสผ่าน (อย่างน้อย 8 ตัว)
4. จากนั้นเครื่องไหนก็เข้าได้ด้วย **ชื่อผู้ใช้ + รหัสผ่าน** อย่างเดียว ไม่ต้องใช้ token อีก
5. เพิ่มผู้ใช้คนอื่น หรือเปลี่ยนรหัสผ่าน ได้ที่เมนู 👤 บัญชี / ประวัติ

บัญชีเก็บเป็นไฟล์ `accounts/*.json` ใน repo นี้ ภายในเป็น token ที่เข้ารหัสด้วยรหัสผ่านของผู้ใช้ (AES-256, PBKDF2 600,000 รอบ)
ชื่อไฟล์เป็นค่า hash ของชื่อผู้ใช้ ดังนั้นควรตั้งรหัสผ่านที่เดายาก และไม่ซ้ำกับที่อื่น

## การทำงาน

- **เข้าสู่ระบบ**: ชื่อผู้ใช้ + รหัสผ่าน ใช้ปลดล็อก token ที่เข้ารหัสไว้ token ไม่ถูกส่งไปที่อื่นนอกจาก api.github.com
- **สำรองอัตโนมัติ**: แก้ไขอะไรแล้ว ประมาณ 6 วินาทีหลังหยุดพิมพ์จะบันทึกขึ้น GitHub เป็นไฟล์ `finance-data.json` (1 ครั้ง = 1 commit)
- **ประวัติ**: เมนู 🕘 ประวัติ / สำรองข้อมูล ดู ดาวน์โหลด หรือกู้คืนเวอร์ชันย้อนหลังได้ และมีสำเนาในเครื่องอีกชั้น
- **หลายเครื่อง**: เปิดโปรแกรมแล้วจะดึงข้อมูลล่าสุดจาก GitHub เอง ถ้าแก้พร้อมกันสองเครื่อง โปรแกรมจะถามว่าจะใช้ของเครื่องไหน
- **ไม่มีเน็ต**: ยังใช้ได้ ข้อมูลเก็บในเครื่องก่อน แล้วสำรองขึ้นเมื่อกลับมาออนไลน์
